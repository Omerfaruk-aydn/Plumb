# PLUMB Roadmap

PLUMB is an open-source, provider-agnostic AI coding agent for your terminal. It
gives you the shortest path from your prompt to a model — any model — with a
lightweight, extensible command-line interface.

This document outlines our approach to the roadmap: our guiding principles and
the key areas we're focused on. It's not a static list but a dynamic set of
priorities tracked live in
[GitHub Issues](https://github.com/Omerfaruk-aydn/Plumb/issues).

As an [Apache-2.0](LICENSE) open-source project, we welcome
[public contributions](CONTRIBUTING.md) and give first priority to contributions
aligned with the roadmap below. To propose a new feature or change, start by
[opening an issue for discussion](https://github.com/Omerfaruk-aydn/Plumb/issues/new/choose).

## Disclaimer

This roadmap represents current thinking and is for informational purposes only.
It is not a commitment or a guarantee of future delivery. The development,
release, and timing of any feature are subject to change as priorities evolve.

## Guiding Principles

- **Power & simplicity.** Deliver access to state-of-the-art models — across
  providers — through an intuitive, lightweight command-line interface.
- **Extensibility.** An adaptable agent for a variety of use cases and
  environments, able to run anywhere.
- **Provider neutrality.** No single vendor should be a hard dependency. Every
  provider integration should feel first-class.
- **Free and open source.** Foster a community where cost isn't a barrier to
  personal use, and where issues and pull requests get resolved quickly.

## Focus Areas

- **Authentication** — API keys, OAuth device-code flows, coding-plan
  subscriptions, and secure credential storage across providers.
- **Model & Providers** — Expanding provider coverage, multi-modality, local
  model execution, and routing/performance tuning.
- **User Experience** — CLI usability, performance, interactive features, and
  documentation.
- **Tooling** — Built-in tools and the MCP (Model Context Protocol) ecosystem.
- **Core** — Core agent loop, context management, and session handling.
- **Extensibility** — Skills, hooks, and custom extensions.
- **Platform** — Installation, OS support, and the underlying CLI framework.
- **Quality** — Testing, reliability, performance, and overall product quality.
- **Background Agents** — Long-running, autonomous tasks and proactive
  assistance.
- **Security & Privacy** — Everything related to keeping credentials and user
  data safe.

## How to Contribute

PLUMB is an open-source project and we welcome contributions from the community
— developers, designers, and enthusiastic users alike. See
[CONTRIBUTING.md](CONTRIBUTING.md) to get started. Ways to get involved:

- **Report bugs** — Open a
  [bug report](https://github.com/Omerfaruk-aydn/Plumb/issues/new) with as much
  detail as possible.
- **Suggest features** — Have an idea? Open a
  [feature request](https://github.com/Omerfaruk-aydn/Plumb/issues/new).
- **Contribute code** — See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on
  submitting pull requests.
- **Write documentation** — Help improve our docs, tutorials, and examples.
