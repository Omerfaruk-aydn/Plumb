Modifications for PLUMB:
- All public-facing APIs renamed to use Plumb prefix
- Adapted for Node.js/npm module system (from Bun workspace origin)
- Streaming transports reimplemented using native fetch API
- Credential storage replaced with AES-256-GCM encrypted storage
- Provider catalog filtered to production-ready subset only
- OMP TUI, agent runtime, and interactive mode excluded
- Google-specific branding removed; Google providers remain as optional entries
